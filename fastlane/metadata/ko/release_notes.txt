버전 1.1의 새로운 기능:

• 전체 화면에서 그날의 사진을 넘겨 보기
• 비디오와 Live Photo 재생
• 더 선명한 확대
• 달력 버튼으로 원하는 날짜 선택
• 위젯을 탭하면 위젯에 표시된 사진이 열림
• 오늘의 사진 수를 보여 주는 새로운 잠금 화면 위젯
• 새로운 연도 위젯: 지난 각 연도의 오늘 사진을 한 장씩 표시
• 위젯의 셔플 버튼으로 오늘의 다른 사진 보기
• Siri 및 단축어: 특정 날짜나 선택한 연도의 사진 보기, 무작위 추억 보기, 오늘 사진 개수 세기
• 위젯 사진이 바뀌는 빈도를 선택하고, 원하면 셔플 버튼을 숨길 수 있음
• 새로운 앱 아이콘
• 8개 언어 추가 지원
• 더 빨라진 로딩
• 스크린샷을 숨기면 사진이 누락되는 문제, 새해 전후의 연도 머리글, 설정 변경이 반영되지 않는 문제 수정
