버전 1.1의 새로운 기능:

• 사진 앱과 같은 새로운 사진 보기: 격자에서 사진이 확대되며 열리고, 아래로 쓸어내리거나 오므려 닫고, 탭하여 모든 것을 가리기
• 축소판 막대로 그날의 모든 사진을 빠르게 훑어보기
• 비디오와 Live Photo 재생
• 오므리거나 두 번 탭하여 확대, 더 선명한 세부 사항
• 지도에서 사진을 찍은 장소 보기
• 원본 사진과 비디오 공유, 즐겨찾기, On This Day에서 가리기, 삭제
• 격자를 오므리거나 벌려 축소판 크기를 바꾸거나, 화면 비율 격자로 사진 전체 보기
• 여러 사진을 한 번에 선택하여 공유하거나 즐겨찾기에 추가
• 가로 모드 지원
• VoiceOver가 모든 사진을 설명
• 달력 버튼으로 원하는 날짜 선택
• 위젯을 탭하면 위젯에 표시된 사진이 열림
• 오늘의 사진 수를 보여 주는 새로운 잠금 화면 위젯
• 새로운 연도 위젯: 지난 각 연도의 오늘 사진을 한 장씩 표시
• 위젯의 셔플 버튼으로 오늘의 다른 사진 보기
• Siri 및 단축어: 특정 날짜나 선택한 연도의 사진 보기, 무작위 추억 보기, 오늘 사진 개수 세기
• 위젯 사진이 바뀌는 빈도를 선택하고, 원하면 셔플 버튼을 숨길 수 있음
• 새로운 앱 아이콘
• 8개 언어 추가 지원
• 더 빨라진 로딩
• 스크린샷을 숨기면 사진이 누락되는 문제, 새해 전후의 연도 머리글, 설정 변경이 반영되지 않는 문제 수정
